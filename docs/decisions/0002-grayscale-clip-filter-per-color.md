# 0002 흑백 CLIP 필터와 색별 비율 남기기

- 상태: 채택
- 날짜: 2026-11-14

## 배경

돌려주는 상품은 새 상품과 *함께 입을* 옷입니다(상의 기획이면 하의). 새 상품의 소재나 핏으로 재고를 거르는 것은 코디 논리에 맞지 않습니다. 반면 trend 결과에는 트렌드 아이템과 비슷해 보이는 이미지(착샷, 상품 이미지)가 있어서, 조합 색상표를 뒤집지 않으면서 소재·질감·디테일의 시각 신호를 더하고 싶었습니다.

## 결정

- 트렌드마다 기준 이미지 1장을 고릅니다. 점수가 가장 높은 착샷, 없으면 점수가 가장 높은 상품 이미지.
- OpenCLIP `ViT-B-32-quickgelu`와 OpenAI 가중치로 임베딩합니다. 흑백 이미지와 영어 소재·디테일 텍스트를 벡터 단계에서 0.6 / 0.4로 합칩니다.
- 같은 규칙으로 미리 만든 인덱스와 비교합니다. 규칙 이름을 인덱스에 저장하고 불러올 때 확인합니다.
- 색마다 상위 10%(최소 1개)를 남깁니다. 후보를 0개로 만들지 않고, 필터를 걸 수 없으면 이유를 남깁니다.

## 결과

- 요청마다 기준 이미지 1장만 임베딩하고 재고 임베딩은 미리 계산해 둡니다.
- 조합 색상표가 고른 색 구성이 필터 뒤에도 유지됩니다.
- 상대적인 잘라내기일 뿐 유사도를 보장하지 않습니다. 어떤 색에 후보가 1개면 항상 남고, 인덱스에 없는 후보는 0점입니다.
- 흑백은 명도를 남기고 이미지 전체를 임베딩하므로 신호가 소재에만 한정되지 않습니다.
- CLIP 없는 경로보다 코디 적합성이 좋아진다는 평가는 없습니다.

## 검토한 대안

- 고정 유사도 기준값: 기준 이미지마다 유사도 수준이 달라(H&M 상품 사진 기준 중앙값 0.81~0.86) 거의 다 남기거나 이미지에 따라 결과가 달라집니다.
- 전체 상위 10%: 흑백에 남은 밝기 차이로 밝은 색이 쏠려 남았습니다.
- 컬러 이미지: CLIP이 같은 색을 선호해 색상표의 보색·대비 조합을 뒤집습니다.
- 한국어 텍스트: 이 체크포인트는 영어 중심이라 도메인 용어를 영어로 바꿔 씁니다.
- FashionCLIP, SigLIP 2, 다른 OpenCLIP 체크포인트, 코디 궁합 모델: 평가하지 않았습니다. 어느 것이든 인덱스를 다시 만들고 정답 라벨로 비교해야 합니다.
