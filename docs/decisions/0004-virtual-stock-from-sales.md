# 0004 판매 기록에서 만든 가상 재고

- 상태: 채택
- 날짜: 2026-11-06

## 배경

H&M 데이터에는 상품과 거래가 있지만 재고, 입고량, 원화 판매가가 없습니다. 과잉재고 순위에는 셋 다 필요합니다.

## 결정

각 상품의 실제 판매에서 정해진 규칙과 고정 시드로 만듭니다. 판매율은 같은 고객군·영역 안의 판매 인기와 마지막 판매의 최근성으로 0.30~0.95 사이에서 정하고, 입고량과 재고는 판매량과 판매율로, 판매가는 거래 가격의 최고값으로 정합니다. 모든 응답에서 이 값들은 `data_nature: sample`로 표시하고 summary에는 "(가상)"을 붙입니다. 세부 규칙은 [랭킹 규칙의 가상 재고](../ranking-rules.md#가상-재고)에 있습니다.

## 결과

- 순위는 재현 가능하고 서로 비교하기에는 그럴듯하지만, 실제 재고 상태는 아닙니다.
- 판매율을 판매에서 만들기 때문에 판매율 지표와 추세 지표가 함께 움직일 수 있습니다.
- 사이즈는 다루지 않습니다.

## 검토한 대안

- 무작위 재고: 수요와 관계가 없어 순위가 잡음이 됩니다.
- 사용자에게 재고 파일 받기: 데이터가 없는 공개 레포의 범위 밖입니다. 실제 재고를 넣을 자리는 `virtual_stock` 스키마입니다.
